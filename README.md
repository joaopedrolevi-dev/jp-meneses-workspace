# JP Meneses Workspace 🚀

Olá! Seja bem-vindo ao **JP Meneses Workspace**, um projeto pessoal que desenvolvi com o objetivo de organizar melhor minha rotina, acompanhar meus objetivos e aumentar minha produtividade.

A ideia surgiu da vontade de criar uma ferramenta própria, prática e moderna, reunindo em um só lugar recursos que facilitam minha organização pessoal.

## 🎯 Sobre o projeto

O JP Meneses Workspace é um aplicativo de organização e produtividade, desenvolvido inicialmente para uso pessoal, com foco em dispositivos Android e possibilidade de utilização em computadores.

## ✨ Funcionalidades

- 📊 **Dashboard:** visão geral da rotina e das atividades.
- ✅ **Tarefas:** cadastro, edição e acompanhamento de tarefas.
- 🎯 **Metas:** criação de objetivos e acompanhamento do progresso.
- 📅 **Calendário:** organização de datas e compromissos.
- 🔔 **Lembretes:** registro de contas, pagamentos e datas importantes.
- 💾 **Armazenamento local:** preservação dos dados no dispositivo.
- 📱 **PWA:** possibilidade de instalação como aplicativo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)
- Service Worker
- Git e GitHub
